# 📌 Sobre o Projeto

O *FocaAí* é um aplicativo criado para ajudar estudantes e profissionais a manterem o foco durante estudos ou trabalho, reduzindo distrações causadas por redes sociais e excesso de uso do celular.

A proposta do aplicativo é incentivar hábitos saudáveis de produtividade utilizando conceitos de *Calm Technology (Tecnologia Calma)*, promovendo uma experiência tranquila, leve e sem sobrecarga visual.

---

 Funcionalidades do Aplicativo

O aplicativo possui as seguintes funcionalidades principais:

 ⏱️ 1. Modo Foco (Pomodoro)
- Cronômetro central para sessões de foco.
- Sons relaxantes para melhorar concentração.
- Temporizador configurável.

 🔒 2. Bloqueio Seletivo
- Escolha de aplicativos que serão bloqueados durante o foco.
- Controle simples por interruptores (ON/OFF).

 🌳 3. Jardim Digital
- Uma árvore virtual cresce enquanto o usuário mantém o foco.
- Caso o usuário abandone a sessão antes do tempo, a árvore morre.

 📈 4. Estatísticas de Tempo Ganho
- Em vez de destacar tempo perdido, o app mostra *tempo ganho para a vida real*.
- Visualização positiva do progresso.

 👥 5. Foco em Grupo
- Criação de salas para amigos focarem juntos.
- Progresso coletivo durante sessões de estudo/trabalho.
